A Universe Named Dillu

Free publishing with GitHub Pages:
1. Sign in to https://github.com/ and create a new public repository named dillu-universe.
2. Upload the contents of this folder (index.html and the assets folder) to the repository root.
3. Open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select main and / (root), then Save.
6. Wait a few minutes; GitHub will show the public website URL in Settings > Pages.

Keep the assets folder beside index.html so all 8 photos and 2 videos load.
